## 实体口径

- 颜汝：特指公开报道中以智焰科技 CEO 身份参与长沙 AI 实操与企业 AI 活动的颜汝，不与游戏账号纠纷当事人、音乐主播或其他同名对象合并。
- 智焰科技：特指“智焰科技（颜汝团队）”，不把数字人公司、“AI颜汝”、上海同名主体、融资、广电合作、自研算法或广州、浙江同名公司自动归入该团队。
